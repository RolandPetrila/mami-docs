# Mami Docs

O aplicație web personală (PWA) pentru organizarea documentelor și asistență AI zilnică.

## Scop

Bibliotecă digitală personală cu agent AI conversațional voce/text, funcționare offline și notificări native pe Android.

## Tech Stack

- **Frontend:** Vanilla JS + Web Components + Vite
- **PWA:** Workbox Service Worker
- **Hosting:** Cloudflare Pages
- **Backend:** Cloudflare Workers
- **Date:** Supabase (PostgreSQL + Storage)
- **AI:** Groq · Gemini · Cerebras · Mistral · și alții
